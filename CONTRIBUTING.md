# Contributing

Thanks for helping. This repository covers the format, the skill and the docs. The Relay service isn't here.

- **Questions and ideas:** open an issue. Say what you're building and what you need from the format.
- **Changes to the schema:** open an issue first. The format is versioned (`v1`); changes that would break existing packages go into a new version.
- **Pull requests:** keep them small and focused. Examples must validate against the schema.
- **Examples:** use the sample names Ana and Jordan, and fictional companies. Never put real people's data in an example.

We aim to reply to issues within a week.
